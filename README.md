## Descripción

Sistema de escritorio para CoopeTica R.L., una cooperativa de ahorro y crédito con varias sucursales. Centraliza el registro de sucursales y asociados, los aportes, las cuentas de ahorro y corrientes, los préstamos con sus cuotas y los reportes, y guarda toda la información en archivos de texto para que se conserve entre sesiones.

## Requisitos

- JDK 25
- Apache NetBeans con soporte para JDK 25
- Git

## Cómo ejecutarlo

1. Clonar el repositorio:
   `git clone https://github.com/SantiagoGM0186/bis04-coopetica-gutierrez-cordero.git`
2. En NetBeans, ir a **File → Open Project** y abrir la carpeta `bis04-coopetica-gutierrez-cordero`.
3. Si NetBeans muestra un aviso para resolver problemas del proyecto, aceptarlo.
4. Compilar con **Clean and Build Project**.
5. Ejecutar con **Run Project**. La ventana principal todavía está en desarrollo; este paso se actualizará cuando exista.
